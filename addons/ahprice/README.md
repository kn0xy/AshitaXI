# AHPrice

AHPrice lets you type an auction house listing price with the number keys instead of using the in-game price spinner.

## Installation

[Download](https://github.com/kn0xy/AshitaXI/releases/download/ahprice/ahprice-1.1.zip) and extract to your `Ashitav4-beta/addons` folder.

## Usage

Load the addon, then open the auction house and go to the price entry screen for a listing. While that menu is open:

- **0-9** : Type digits into the listing price.
- **Backspace** : Remove the last digit.
- **Delete** : Clear the entire price.

The price is written into the auction house menu as you type.

Number keys are only captured while the auction house is open and chat input is closed. Typing in chat is not affected.

There are no slash commands. Simply load it with `/addon load ahprice`.
